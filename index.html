Respaldo y portabilidad
Los datos se guardan automáticamente en este navegador. Para llevarlos a otra PC, exportá el archivo JSON y luego importalo ahí.
"Vincular archivo de datos" te pide elegir una vez el archivo qa-bcr-suite-data.json que está junto a este HTML. Después, "Guardar en archivo" te pregunta antes de sobrescribirlo con los datos actuales.
Esta función solo funciona en Chrome/Edge, y solo si la página no se abrió con doble clic directo (necesita servirse desde un servidor local o similar). Si no está disponible, usá "Exportar" e importalo manualmente.
